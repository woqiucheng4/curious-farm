# 知趣农场 · 起步原型

这是"知趣农场"项目的起步代码，已经验证可以正常运行：点击地面移动、拖拽旋转视角、
靠近幼苗按住鼠标浇水（含完整的输入/过程/反馈/取消/失败恢复）。

详细的开发指南请看仓库根目录的
[`docs/知趣农场_技术开发文档_面向初级开发者.md`](../docs/知趣农场_技术开发文档_面向初级开发者.md)，
产品设计请看
[`docs/知趣农场_产品方案_v3.md`](../docs/知趣农场_产品方案_v3.md)。

## 快速开始

```bash
npm install
npm run dev
```

打开终端里提示的地址（通常是 `http://localhost:5173`）。

- 左键点击地面：角色走过去
- 右键按住拖拽：旋转视角
- 左键点击幼苗：够不到会提示"太远了"并自动走近；走近后按住左键浇水，松开停止

## 其他命令

```bash
npm run build    # 类型检查 + 打包，用于验证代码没有编译错误
npm run preview  # 预览打包后的产物
```
