# Curious Farm（知趣农场）

小学三年级向的 Web 3D 学习农场：点击移动、右键拖拽视角、按住左键与物体交互（起步原型已实现浇水）。

## 仓库结构

- `app/` — Vite + TypeScript + Three.js 可运行原型（`npm install && npm run dev`）
- `docs/` — 产品方案 v3、面向初级开发者的技术文档、设计方案 v2

## 本地运行

```bash
cd app
npm install
npm run dev
```

浏览器打开终端里显示的本地地址即可。
