# 知趣农场 · 里程碑 A 剩余开发清单（不含 UI 美化）

日期：2026-11-17。依据：`知趣农场_产品方案_v3.md` 与 `知趣农场_里程碑A_交付说明.md`。

**范围约定**：本清单只含功能、业务、场景逻辑、测试与工程质量。画面美术（模型、贴图、光照、天空、动画资产）统一放到最后的视觉升级阶段，本清单不做。仅保留"可读性底线"（见 §0）。

## 0. 全局规则（所有任务都要遵守）

1. **逻辑与外观分离**：每个物体的行为类不得直接依赖具体几何体或材质，外观通过独立的"视图"层创建，后续换美术只改视图层。
2. **可读性底线**（不是美化）：未成熟/成熟、可交互/不可交互必须有明显的颜色或大小差异；悬停有高亮；提示文字清晰。
3. **取消与失败不扣资源、不写学习事件**，沿用现有规则。
4. **资源结算按任务实例 ID 去重**，沿用现有规则。
5. 题目全部原创，不复制外部题库；不诊断智力、性格或学习障碍；题量少时保持"证据不足"，不输出假精度。
6. 每个任务完成后：`npm run build` 通过，自动化测试通过，更新交付说明，commit 并 push。

## 1. 已完成（无需重做）

拿取、浇水、喂食确认、收获四动作；胡萝卜、苹果树（4 个独立苹果）、双小鸡；离线存档；12 个数据驱动学习任务（语数英各 2 个知识点，基础题加迁移题）；学习证据与"证据不足 / 初步会"规则解释；任务去重；未成熟拒绝路径实测。

## 2. 剩余工作

优先级：P0 = 首局试玩前必须有；P1 = 里程碑 A 验收需要；P2 = 可延后。

### 2.1 业务：低门槛行为（产品方案 §4.2）P0/P1

| 编号 | 内容 | 验收标准 |
|---|---|---|
| L1 | 成长记录/相册：按时间记录关键事件（发芽、成熟、收获、小鸡长大、第一次采摘） | 刷新后保留；不依赖学习资源；可随时查看 |
| L2 | 动物改名：小鸡可改名，名称存档 | 名称限长并过滤空白；刷新保留；不消耗任何资源 |
| L3 | 农场币装饰购买：至少 3 种简单装饰可购买并摆放 | 只用农场币；资源（水/阳光/肥料/饲料）不能用农场币购买；存档 |
| L4 | 工具架农事预览：靠近工具架显示"接下来可以做什么" | 不消耗资源，仅展示；内容随农场状态变化 |
| L5 | 呼唤/抚摸（抚摸已有）：补充呼唤小鸡，小鸡转向或走近 | 不改变成长状态 |
| L6 | 远观成熟作物：成熟后不强制收获 | 成熟状态可长期保留且不惩罚 |

### 2.2 业务：经济与奖励 P1

| 编号 | 内容 | 验收标准 |
|---|---|---|
| E1 | 农场币来源与出售：收获物可"出售或留仓"（产品方案 §7 第 6 步） | 出售得农场币，留仓保存；两种选择都存档 |
| E2 | 种子购买：用农场币买种子（产品方案 §4.1） | 阳光、水、肥料、饲料不能用农场币购买 |
| E3 | 鸡蛋用途：成年母鸡产蛋可出售或留仓 | 与 E1 共用逻辑 |
| E4 | 奖励规则补全（产品方案 §4.4）：独立完成完整奖励；使用提示后用新题确认也有奖励；到期复习作为新任务可再次获得奖励 | 重复提交不重复发奖；各路径有单元测试 |

### 2.3 业务：学习内容与证据 P0/P1

| 编号 | 内容 | 验收标准 |
|---|---|---|
| C1 | 每个知识点补齐四类题：教学演示、两道基础题、一道迁移题、一道延后复习题（产品方案 §6） | 题目数据在 `taskData.ts` 类数据文件；每题有来源与审核状态字段 |
| C2 | 每科知识点扩到 2~3 个（当前每科 2 个，可补到 3 个） | 全部原创；覆盖产品方案 §6 示例中的适合项 |
| C3 | 农事化任务形式：至少 3 种非选择题的场景内操作，例如把 12 份饲料平均放进 3 个食槽、摆围栏、按订单装篮 | 判定基于场景操作结果；错误时保留结果供比较，不直接判失败 |
| C4 | 提示机制：答错或求助时提供分级提示 | 使用提示后须通过新题才算确认；记录是否用提示 |
| C5 | 延后复习：另一学习日出现的复习任务 | 满足"较稳定"证据条件；使用可注入的时间源，便于测试 |
| C6 | 学习证据状态机补全（产品方案 §9）：证据不足 → 初步会 → 较稳定 | 较稳定需不同学习日的独立变式；单次错题不下结论；两次错只作补测理由 |
| C7 | 成长记录页中的"今日变化与知识证据摘要"（产品方案 §7 第 7 步） | 只展示有证据的知识点，措辞不诊断 |
| C8 | 题库治理：数据 schema 校验脚本，检查必填字段、答案合法、选项无重复、ID 唯一 | 构建或测试阶段自动运行 |

### 2.4 场景与玩法 P1

| 编号 | 内容 | 验收标准 |
|---|---|---|
| S1 | 果篮独立对象：可交互，显示苹果与蛋的数量，可选"放回原位"（产品方案 §5.4） | 数量来自存档数据，刷新恢复 |

## 3. 需要人工决策（AI 不得自行决定）

1. **每日保底资源**（产品方案 §4.3）：采纳与否。
2. **教材版本**：人教版、北师大版、苏教版等，决定题目年级与内容。
3. **题目审核责任人**：谁负责首批题目审核。
4. **苹果再结果规则**：里程碑 A 已暂缓，是否在 A 之后加入。
5. **商业模式**：是否收费，影响资产与数据授权口径。
6. **试玩人选**：目标年龄孩子或未接触项目的同事。

## 4. 建议顺序

1. Q1、Q2、Q8、G4：测试底座与时间源（后面所有任务都依赖）。
2. D1~D3：存档版本与导入导出（试玩换设备要用）。
3. T1~T3：首局引导、目标提示、暂停继续。
4. L1~L6、E1~E4：低门槛行为与经济。
5. C1~C8：学习内容与证据补全。
6. S1~S6：场景补全与碰撞。
7. Q3、Q5：端到端测试与 CI。
8. T4、T5、G1~G3：进阶移动、触屏、结构整理。
9. V1~V4、Q6、Q7：试玩准备与基线。
10. 试玩，根据结果决定下一步（视觉升级或调整玩法）。

- UI 与视觉美化、模型和贴图、光照与天空、动画资产。
- 里程碑 B：在线 AI 分析、家长入口与开关、完整 24 知识点与 96 题、更多物种与分区、知识图谱全量接入。
- 苹果再结果、骑马、复杂繁殖、自由建造。
