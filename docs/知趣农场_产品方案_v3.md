修订日期：2026-11-17。本版是独立、完整的产品文档，不需要先读 v1/v2 才能理解；文末附修订记录，说明相对 v2 补充和完善了什么。

## 1. 产品定位

一款在电脑浏览器运行的 3D 农场游戏，面向小学生，首段体验以三年级为起点、年级可配置，后续向下覆盖一二年级、向上覆盖四至六年级乃至初高中。孩子通过完成语文/数学/英语的短学习任务获得阳光、水、肥料、饲料，亲手播种、浇水、喂食、收获，看着作物和动物从小长大。

**要解决的问题**：此前版本"参与感弱、操作看不懂、做题无趣"。这一版把第一人称亲手操作(拿取/浇水/喂食/收获)作为核心卖点，并把学习任务和农事动作直接绑定，而不是"做完题再看一段动画"。

---

## 2. 核心体验与循环

孩子接手一座小农场，选择想种的作物、给动物起名，在照料它们的过程中完成学习任务。

**核心循环**：发现农场需求 → 学习并动手解决问题 → 获得资源 → 亲手照料 → 看见成长 → 收获与布置 → 规则/AI推荐下一次学习。

学习任务与农场情境直接挂钩，例如分饲料练平均分、安排菜畦练乘法、读采购单练提取信息、递送果篮练英语。不适合自然融入农事的内容放到"农舍学习角"，用短课与练习获得同样的资源。

## 3. 农场组成与成长

首版地图包含一块菜地、一棵果树、一个鸡舍、工具架、水箱、果篮（对应里程碑A，范围已收缩，见第9节）；完整版再扩展到菜地/果园/鸡舍/农舍学习角/仓库/小集市六个区域。

| 对象 | 看得见的成长阶段 | 操作与产出 |
|---|---|---|
| 胡萝卜 | 种子 → 发芽 → 长叶 → 可收获 | 播种、浇水、照料；拔出装篮或售卖 |
| 番茄（后续） | 种子 → 幼苗 → 开花 → 绿果 → 红果 | 搭架、浇水、营养管理；成熟后分批采摘 |
| 玉米（后续） | 种子 → 幼苗 → 长高 → 结穗 → 成熟 | 收获后出售，或加工成鸡饲料 |
| 苹果树 | 树苗 → 小树 → 成树 → 开花 → 青果 → 熟果 | 持续保留，采摘后进入下一轮开花结果 |
| 小鸡 | 雏鸡 → 小鸡 → 成年母鸡 | 喂食、添水、清洁；成年后完成照料周期即产蛋 |

**生长驱动规则**：由"已完成的学习+已投入的资源+已达成的照料里程碑"共同驱动，不挂钩真实时钟。离线时保留进度，不因断签、答错或资源不足导致植物枯死、动物生病；缺资源时显示"等待照料"而非惩罚性状态。

**里程碑 A 取舍**：苹果树的成熟果实采摘后保留“已采摘”状态，本阶段不进入下一轮开花结果；再结果作为后续阶段内容，不以真实时间驱动。

## 4. 资源与学习的关系

### 4.1 仍需要学习资源的行为

播种（阳光）、浇水（水）、追肥（肥料）、补充饲喂（饲料）——这些真正推进生长的动作，与对应学科的学习任务挂钩。语数英均能提供阳光、水和肥料，资源类型对应学习环节、不固定对应某一学科；稀缺资源旁提供"去完成一个合适任务"的入口，按当前年级和学习状态智能选择，避免因某科尚未开放而卡住。

种子可用农场币购买；阳光、水、肥料、饲料不能用农场币绕过学习获得。

### 4.2 不需要学习资源的低门槛行为（解决"农场变刷题入口"风险）

- 自由行走、观察农场全貌。
- 抚摸/呼唤已拥有的动物（简单互动，不影响成长状态）。
- 远观已成熟但暂不收获的作物。
- 翻看成长记录/相册，查看过去发生的变化。
- 用已有农场币购买装饰、给动物改名。
- 在工具架旁预览接下来可以做的农事（不消耗资源，仅展示）。

这样即便孩子当天状态不好、暂时不想做题，仍有合理的事可做，农场不会退化为"先做题才能摸"的纯粹入口。

### 4.3 待讨论事项：每日保底资源【新增，待讨论，非既定设计】

可以讨论是否加入"每日一小笔免费资源"（例如够浇1~2株），避免完全卡住。这触碰了"不能绕过学习"的既定约束，是否采纳需要产品侧明确决定，这里只作为选项列出。

### 4.4 奖励发放规则

奖励以"完成一次学习小任务"为单位：第一次独立完成有完整奖励；使用提示后通过新题确认也有奖励；同一任务重复提交不重复发奖；到期复习是新任务，可再次获得奖励。资源结算以任务实例ID去重，动画、连点、刷新和重试均不能多发。动物的第一份饲料可由学习任务获得，避免"先养鸡才能种玉米、先种玉米才能养鸡"的循环依赖。

## 5. 第一人称四大核心动作规格

统一结构：**输入 → 过程 → 反馈 → 取消 → 失败/纠错恢复**。默认移动方案为点击地面行走 + 拖拽旋转视角，不强制学习键盘；为熟悉操作的孩子/家长提供可选的"进阶模式"（WASD + 自由视角）。这两种移动方式的实际体验（是否晕动、是否保留了"自由走动"的真实感）仍需第9节的验证流程实测。

### 5.1 拿取
- 输入：靠近可拿取物体，高亮提示，点击触发。
- 过程：约0.3~0.5秒的伸手—抓握动画。
- 反馈：物体吸附到手部；原处留下"已拿走"标记。
- 取消：动画进行中再次点击，物体留在原地，不产生记录。
- 失败恢复：距离过远/物体被占用时播放"够不到"动效，可立即重试，不计入失败次数。

### 5.2 浇水
- 输入：持壶瞄准目标，按住倾倒，松开停止。
- 过程：壶嘴出水，水滴命中点出现涟漪，土壤随湿润度变色。
- 反馈：水壶余量随有效浇灌量减少；湿润度达阈值显示"已浇好"。
- 取消：移开瞄准或松手，立即停止。
- 失败恢复：瞄准无效区域时不消耗水、只给"没有效果"的轻反馈；水用完自动停止并提示，不算失败。

### 5.3 喂食（统一工作台式与场景式两种呈现）
- 输入：舀取一份 → 移动到食槽上方 → 倾倒。
- 过程：每次舀取固定一份，倾倒时饲料洒落、食槽堆积可见。
- 反馈：食槽实时显示份数；动物转头靠近。
- 取消：倾倒前可把手中一份倒回料袋；已倒入但未确认的份数可"取出"。
- 失败恢复：全部动作完成后弹出"确认分配"面板，供核对调整；**只有点击确认后才真正扣减资源、写入学习记录**，操作失误不计入知识判断。

### 5.4 收获
- 输入：靠近成熟果实，点击/长按触发采摘。
- 过程：伸手—抓握—脱离—入篮。
- 反馈：篮内数量增加；原位置标记"已采摘"，不可重复采摘。
- 取消：抓握阶段松开，果实留在原处。
- 失败恢复：未成熟果实拒绝被摘或摘下后弹回原位，提示"还没熟"；带条件任务（如"只摘成熟番茄"）摘错后允许"放回原位"，不直接判定任务失败。

## 6. 把知识点变成可参与的农事（示例）

以下为本方案原创示例，正式教学年级需要按教材版本审核（教材版本目前未指定，见第12节）。

| 学科与目标 | 孩子实际做什么 | 判断依据与反馈 |
|---|---|---|
| 数学：平均分 | 把12份饲料平均放进3个食槽 | 各槽4份、总数仍为12；数量不等时保留结果，让孩子比较 |
| 数学：乘法 | 菜畦里种3行每行4株，预测总数 | 行列操作与"3×4=12"对应 |
| 数学：分数 | 按订单把8个苹果的四分之一装篮 | 装入2个，并用均分的四组解释其中一组 |
| 数学：周长 | 为长6格宽4格的菜地摆放围栏 | 检查四边长度与总长20格；区分周长和面积 |
| 语文：提取限制条件 | 阅读"采摘6个成熟番茄，青色的留在枝上"，在场景中采摘 | 数量和成熟条件都满足；解释遗漏的是哪条要求 |
| 语文：表达顺序 | 给播种、浇水、发芽、长叶四张观察卡排序 | 先检查顺序；开放表达按内容与语言规则给建议 |
| 英语：物品数量颜色 | 读/听"Two red apples, please."，从果篮中挑选递送 | 同时匹配物品、数量、颜色；阅读和听力成绩分开记 |
| 英语：方位 | 按"The basket is under the tree."摆放篮子 | 检查相对位置；文本、音频模式分别记录 |

每个知识点至少准备：一次教学演示 + 两道基础确认题 + 一道迁移题 + 一道延后复习题，共四道独立审核题，全部自行创作并人工审核（不直接套用外部题库的题目内容）。

## 7. 第一局体验流程（示例，待验证）

默认演示为三年级，用已学知识完成第一局：

1. 0~1分钟：认领农场，给农场和小鸡起名，只显示"把种子放进土里"一个目标。
2. 1~4分钟：读懂种植要求，完成理解检查获得阳光，播种，出现发芽动画。
3. 4~8分钟：观察平均分示范，把12小杯水分到3行，获得水，亲手浇灌。
4. 8~11分钟：完成简短英语喂养订单，获得饲料并投喂，小鸡走向食槽啄食。
5. 11~14分钟：换情境把8个果实平均装进2个篮子，验证能否迁移，获得肥料。
6. 14~16分钟：第一次收获，决定出售还是留仓。
7. 16~18分钟：看成长记录，展示今天发生了什么变化、哪些知识有证据支持、下一次建议。

时间是体验目标，不用倒计时催促答题；孩子可随时暂停，下次从当前操作继续。

## 9. AI 分析与学习证据状态机

可确定的答案由规则判分，AI 只负责解释与推荐；开放表达由规则+AI辅助评价，不确定结果标"待确认"，不据此扣资源或阻断成长。

状态：未测 / 学习中 / 初步会 / 待巩固 / 较稳定。

- 新题独立完成且能通过不同形式的确认题，可进入"初步会"。
- 出现矛盾证据或依赖提示，进入"待巩固"，给出具体原因。
- 另一学习日完成独立变式和迁移检查后，才支持"较稳定"。
- 题量过少保留"证据不足"，不输出假精度（如"掌握率93.7%"）。
- 一次错题不直接给出根因结论；两次出错也只能成为补测理由，不自动认定"真不会"或"粗心"；不诊断智力、性格或学习障碍。

## 11. 开发前的验证流程（5~8分钟，先做这个）

**场景范围**：一小块菜地、一棵可采摘果树、一个鸡舍、工具架、水箱、果篮。

**做什么**：直接给予已领到的资源跳过学习任务环节 → 用点击移动走到各处 → 拿壶接水浇1株苗 → 故意浇错一次位置看反馈 → 喂2只小鸡 → 故意喂错/超量看能否在确认面板调整 → 摘1~2个果实，刻意引导摘一个未成熟的看能否识别/放回 → 自由调换顺序。

**暂缓**：真实学习任务/答题、AI分析报告、知识图谱、家长入口、长期成长演化、多物种多区域解锁、存档与离线细节。

**成功标准**：不经讲解30秒内知道该做什么；四动作都能完整走完且无明显穿模；犯错后能自行判断并重来；移动无明显不适；资源用完前愿意连续做完四个动作。

**失败标准**：反复尝试超过3次仍不知道怎么操作；成功和失败画面无区别；犯错后明显卡住；移动环节头晕或迷路超过1分钟；完成一轮后对再玩一次没有反应。
